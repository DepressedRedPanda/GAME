# First Playable: Third-Person Aiming & Shooting (Blueprint-first)

Objective
- Add a simple hitscan pistol fire to BP_PlayerCharacter that reduces Ammo and damages target actors.

Prerequisites
- Unreal Engine 5.5.4 installed
- A project created from the Third Person (Blueprint) template named HeavyMettle
- Content/HeavyMettle/Maps/L_Dustfall generated by running Scripts/build_dustfall.py in the Editor (optional)
- BP_PlayerCharacter available (copy the template's BP_ThirdPersonCharacter and rename to BP_PlayerCharacter)

Step-by-step (click-by-click)

1) Create input action
- Edit → Project Settings → Input
- Under Action Mappings, add new mapping named "Fire" and bind to Left Mouse Button

2) Open BP_PlayerCharacter
- Content Browser → ThirdPersonBP/Blueprints → Copy BP_ThirdPersonCharacter into your project content (if you're using the template's file)
- Rename to BP_PlayerCharacter and open BP

3) Add variables
- Add variable: Ammo (Integer) default 30
- Add variable: FireRate (Float) default 0.2
- Add variable: IsFiring (Boolean) default false
- Add variable: Damage (Float) default 25.0

4) Implement firing logic
- Event Graph: Right-click → Add Event for InputAction Fire (Pressed)
  - On Pressed: Set IsFiring = true → Call Custom Event StartFiring
- Add Event for InputAction Fire (Released)
  - On Released: Set IsFiring = false

- Custom Event: StartFiring
  - Branch: Ammo > 0?
  - Get FollowCamera (or Camera component) → Get World Location and Get Forward Vector
  - Trace Start = CameraLocation
  - Trace End = CameraLocation + CameraForward * 10000
  - LineTraceByChannel (Start, End, Trace Channel = Visibility)
  - Break Hit Result: If Hit Actor is valid → Call "Apply Damage" or use node "Apply Damage" with Damage input
  - Spawn Emitter at Location (optional muzzle flash) at a Muzzle socket on mesh
  - Decrement Ammo by 1
  - Delay (FireRate)
  - Branch: IsFiring? → If true, Call StartFiring (loop)

5) Add simple UI debug
- Print Ammo value after firing (Print String node) to verify

6) Test in Editor
- Compile and Save BP
- Click Play (PIE) in the generated level or default sample map
- Press Left Mouse Button: expect Ammo to decrement and hit actors to receive damage

Verification checklist
- Left click reduces Ammo by 1 and continues while holding
- Hit actors: if you have a dummy actor with Health variable, its health decreases by Damage value
- No infinite-loop crashes: Stop firing when Ammo == 0 or IsFiring false

Commit message suggestion
- "Implement basic hitscan pistol fire in BP_PlayerCharacter (Blueprint)"

Common pitfalls & fixes
- If LineTrace misses at close range: consider using a short sphere trace from the weapon's muzzle instead of camera-based trace
- If firing uses camera but projectile appears from character location: use a Muzzle socket and spawn FX at socket location while using camera trace for hit detection
